# Roadmap

## Vision

Turn recordings of natural multi-person interaction into analysable multimodal feature
time series, covering the part annotation tools do not: automatic alignment, feature
extraction, quality control, and assisted coding.

## Completed features

### 0.1.0-alpha
- Framework scaffold. No working implementation yet.

## Milestones

- **0.2** Configuration, session discovery, feature store, local execution, prosody
- **0.3** Transcription, speaker identity, turn structure
- **0.4** Pose, face, motion energy
- **0.5** Quality control reporting, rule-based and LLM coding
- **0.6** ELAN interchange, GUI, cluster job scripts
